# داشبورد هوش تجاری کنترل کیفیت خودرو

نمونه نمایشی فارسی و راست‌چین برای ارائه در جلسه کنترل کیفیت؛ نوشته‌شده با Next.js App Router، TypeScript، Recharts و فونت محلی وزیرمتن. تمامی داده‌ها ساختگی هستند و هیچ عدد، هدف، نام تأمین‌کننده یا اقدام این پروژه نشان‌دهنده عملکرد واقعی سایپا نیست.

## اجرا

```sh
npm ci
npm run dev
```

برای میزبانی ایستا: `npm run build`. فایل‌های خروجی در `out/` ساخته می‌شوند. پروژه هیچ API، بک‌اند، پایگاه داده یا سرویس احراز هویتی ندارد. برای میزبانی در زیرمسیر، `NEXT_PUBLIC_BASE_PATH` را پیش از build تنظیم کنید. GitHub Actions این مقدار را برای Pages روی `/saipa_qc` قرار می‌دهد. دستور `next start` برای خروجی export مناسب نیست؛ از یک میزبان ایستا استفاده کنید.

## بخش‌ها

نمای مدیریتی، پارتوی عیوب، مقایسه خطوط و شیفت‌ها، کیفیت تأمین‌کنندگان و PPM، هزینه کیفیت، نمودار کنترل افراد برای گشتاور اتصال، اقدامات اصلاحی و تعاریف شاخص‌ها. پروپوزال چهار صفحه‌ای در `public/proposal.pdf` و نسخه قابل چاپ آن در `public/proposal.html` قرار دارد.

فیلترها دوره ۳۰ / ۱۴ / ۷ روز پایانی مهر، محصول و شیفت را بر داده تولید، تأمین‌کنندگان، هزینه و اقدامات اعمال می‌کنند. فیلتر تولید بر داده مستقل SPC اعمال نمی‌شود؛ SPC انتخاب محصول مستقل و توضیح دامنه دارد. خروجی CSV دقیقاً رکوردهای تولید فیلترشده را صادر می‌کند. گروه عیب قابل انتخاب و جزئیات اقدام قابل بازکردن است.

## داده و تعاریف

`lib/data.ts` شامل ۱۸۰ رکورد تجمیعی ساختگی (۳۰ روز × ۳ خط/محصول × ۲ شیفت) با تولید قطعی است. هر خط یک محصول و یک تأمین‌کننده نمونه دارد؛ مقایسه اثر مستقل خط، محصول یا تأمین‌کننده با این داده ممکن نیست. تعداد بازرسی برابر مجموع قبول بار اول، دوباره‌کاری و ضایعات است. رخداد عیب می‌تواند از خودروهای نامنطبق بیشتر باشد. جمع هزینه تنها بازرسی، دوباره‌کاری و ضایعات را پوشش می‌دهد؛ پیشگیری و شکست بیرونی در این نسخه محاسبه نشده‌اند. همه هزینه‌ها تخمینی و نمایشی‌اند.

FPY = قبولی بدون اصلاح در بازرسی اول / بازرسی‌شده × ۱۰۰. PPM ورودی = قطعات نامنطبق / قطعات بازرسی‌شده × یک میلیون. اهداف و آستانه‌ها قراردادی و نمایشی هستند، استاندارد الزام‌آور نیستند. SPC شامل ۳۰ نمونه مستقل با ۲۰ نمونه مبنا است؛ CL برابر میانگین مبنا و UCL/LCL برابر CL ± ۲٫۶۶ × میانگین دامنه متحرک است. سیگنال فقط خروج از حدود است؛ بررسی سایر قواعد، پایداری مبنا و قابلیت فرایند به داده واقعی نیاز دارد.

## اعتبارسنجی

```sh
npm run typecheck
npm test
npm run build
```

بررسی داده شامل تطبیق خودروها، هزینه‌ها، پارتو، ۳۶ ترکیب فیلتر و سیگنال SPC است. رابط در دسکتاپ و موبایل بررسی می‌شود. هیچ ادعای صرفه‌جویی یا ROI واقعی از این داده نتیجه‌گیری نشده است.
